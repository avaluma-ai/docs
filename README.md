# Avaluma Docs

Customer documentation for [Avaluma](https://avaluma.ai), published at
[docs.avaluma.ai](https://docs.avaluma.ai) with [Mintlify](https://mintlify.com).

- Pages are MDX in `de/` and `en/`; both languages mirror each other.
- Navigation lives in `docs.json`.
- Merging to `main` deploys the site.

## Local preview

```bash
npx mint dev          # http://localhost:3000
npx mint broken-links # check internal links
```

Writing style and conventions: [AGENTS.md](AGENTS.md).
